## 후속 개선 반영

사용자의 “개선 반영해” 후속 지시에 따라 같은 로컬 수집 경로를 보완했다. 위 본문 중 MT 혼합 공지와 불명확한 버튼 차단에 대한 미해결 기록은 이 후속 결과로 갱신한다.

- 자동 브라우저에서 네이버 `공지 숨기기`가 실제로 켜진 것을 확인했다. 기존 목록 수집 전에 공개 공지를 표시하며, 댓글 이동 링크를 정규화 전에 제외해 제목 덮어쓰기를 막는다. 개강 원문 2039가 탐색 순위 1번으로 복구됐다. 본문은 실제 viewer 텍스트가 로드된 후 읽고 로딩 실패를 빈 일정으로 처리하지 않는다.
- MT 소개가 앞에 붙어도 명시적인 강습 제목/하나의 강습 공지/실제 개강일이 있는 경우 그 원문 구간을 사용한다. 제목이나 강습 안의 MT, 경계가 여러 개거나 날짜가 없는 글은 기존처럼 제외한다. 동호회별 예외 목록을 만들지 않았다.
- 요일반별 첫 개강 진술을 별도 후보로 분리한다. 공통 교차·중복수강 안내를 보존하며, 후보 제목은 원문 반 이름과 개강일을 사용한다. 긴 강습 제목이 `위 수업 중 하나만 신청해도` 같은 안내 문장으로 대체되지 않는다.
- 1월 최초 작성일과 갱신된 9월 개강 사이의 연도 오판을 수정했다. 작성 연도 전후 1년이라는 기존 범위를 유지하고, 명확한 요일반 개강 진술과 일치하는 유일한 연도를 사용한다. 일반 소셜의 요일로 연도를 옮기는 변경은 기존 과거 소셜 회귀검사에서 실패해 제외했다. 원문 `강남역 라틴바`는 기존 장소 `클럽 라틴`으로 연결한다.
- Instagram 자동 프로필에는 실제로 `님의 게시물을 놓치지 마세요 / Instagram에 가입 / 로그인` 대화상자가 있었다. 게시물 이미지가 뒤에 보여도 접근 실패로 중단하고, 체크포인트를 완료로 갱신하지 않는다. 초기·도중 로그인 창, 숨겨진 창과 일반 로그인 링크의 구분을 검사했다. 로그인 복구 전 무인 소셜 수집 성공을 주장하지 않는다.
- 본문에 살사 단어가 없고 원본 포스터에만 있는 게시물은 기존 이미지 AI 판독으로 보낸다. 해당 회차 근거의 살사 명시와 기존 AI 검증을 통과해야 한다.
