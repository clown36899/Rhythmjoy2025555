## 운영 확인과 남은 단계

기존 `prepareCandidate` / `buildCafe24Payload` 검증 및 `node scripts/test-ingestion-standards.mjs` 통과 후 인증된 수집 API로 저장했다. 저장 응답은 신규 3·중복 0·제외 0이고, 운영 원장 재조회에서도 pending 3·서버 저장 원본 포스터 3을 확인했다. 공개 업로드 3장의 HTTP 200과 PNG 원본 1587×2245 크기도 확인했다. 직접 DB INSERT나 임의 관리자 세션 사용은 하지 않았다.

기존 자동등록은 등록된 출처/활동 범위와 근거 검증을 요구한다. 이번 소스의 `ready=false`, `mode=manual`을 유지했으며 출처 ID를 기존 스윙 소스로 위장하지 않았다. 사용자의 관리자 화면으로 등록할 수 있으나 현재 컴퓨터 제어 도구가 Mac 잠금을 보고하여 접근하지 못했다. 사용자가 잠금을 해제하면 저장한 후보를 기존 등록 화면에서 이어 처리할 수 있다.

이 결과는 서울 살사 일정 전수수집이나 정기 자동등록 설정 완료가 아니다. 신규 확정 일정은 실제 운영 원문 단위로 추가해야 한다.
