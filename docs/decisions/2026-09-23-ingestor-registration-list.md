# 인제스터 등록 완료 항목의 목록 소유

- 날짜: 2026-09-23
- 상태: 채택, 로컬 구현·검증 완료, 미배포

사용자는 자동 등록에 성공한 항목을 수집 대기에서 빼고 ‘이미 등록’에 모으도록 요청했다. 기존 `6bb55e5a1`은 완료 혜택도 혜택 탭에 모으는 정책이었으나, 등록 상태와 검수 대기의 구분을 흐렸다.

기존 `scraped_events.status=collected` 또는 `is_collected=true`를 완료 목록의 기준으로 유지하고, 혜택 분류나 과거 `_duplicate` 근거보다 우선한다. 완료 항목은 ‘이미 등록’에만 표시하고 신규·혜택·중복 대기 탭에서는 제외한다. 후보 원장은 등록 이력으로 보존한다. 실제 일정 저장 후 연결하는 기존 등록 API, 미등록 후보의 완료 처리 금지, 과거 완료 및 레거시 상태 호환을 유지한다.

상태 판정 책임은 기존 `filterScrapedRows`, 완료 저장 책임은 `buildCollectedScrapedEventRow`에 둔다. 화면은 기존 조회를 화면 복귀와 활성 상태 60초 주기에 재사용한다. 편집/등록 중에는 자동 갱신을 멈추며 실패 응답으로 성공한 목록과 건수를 지우지 않는다.

새 필드·스키마·작업 큐·별도 등록 경로를 만들지 않는다. 운영 DB 재작성이나 마이그레이션은 없다. 되돌릴 때는 목록 필터와 화면 갱신 변경만 되돌리며 실제 등록 일정과 원장은 유지한다.
