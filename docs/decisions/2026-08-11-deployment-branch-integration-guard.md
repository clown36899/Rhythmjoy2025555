# 운영 배포 브랜치 통합 검증

- 날짜: 2026-08-11
- 상태: 채택

## 배경

서로 갈라진 작업 브랜치에서 순차적으로 전체 배포하면서, 먼저 `main`에 반영·배포된 자유게시판 및 사이트 전역 이미지 드래그 수정이 이후 배포 산출물에서 빠졌다. 빌드와 서비스 상태는 정상이었지만 배포 소스가 최신 수정 전체를 포함하는지는 검증하지 않았다.

## 결정

Cafe24 운영 배포는 다음 조건을 모두 만족할 때만 시작한다.

1. 배포 HEAD가 최신 `origin/main`을 포함한다.
2. 추적·미추적 프로젝트 변경이 없는 깨끗한 작업 트리다.
3. 현재 브랜치에 upstream 원격이 있고 로컬 HEAD와 upstream HEAD가 같다.
4. 기능 브랜치에서 배포할 때도 최신 main을 먼저 통합하며, 병렬 브랜치의 일부 파일만 임의로 덮어쓰지 않는다.

## 결과

이미 운영에 반영된 수정이 오래된 병렬 브랜치의 전체 배포로 사라지는 것을 배포 시작 전에 차단한다. 검증 실패 시 빌드·전송·서비스 재시작은 수행하지 않는다.
