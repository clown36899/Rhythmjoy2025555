# 공개 장르는 스윙과 살사만 활성화

- 날짜: 2026-09-11
- 상태: 적용·배포 완료 (d8a02eff, version 1789061116928, 운영 PC·모바일 6경로 통과)
- 요청: 공개 화면에서 스윙·살사만 활성화하고 바차타·탱고·스트릿 버튼은 준비중으로 남긴다. 기존 화면의 형식은 유지한다.
- 기존 구현: 일부 있음. danceTaxonomy의 공통 장르 목록과 normalizeVisibleDanceScope, 각 화면의 기존 장르 버튼이 있다. 9e713ab8에서 기존 화면을 재사용하도록 복구하면서 공개 호출부에 확장 장르 전체 허용이 연결됐다.
- 결정: 기존 목록에 공개 활성 여부 publicAvailable만 둔다. 별도 장르별 설정·DB·페이지를 만들지 않는다. 공개 선택/URL은 기존 정규화 함수를 사용하고, 관리 편집의 명시적 확장 권한은 유지한다. 비활성 버튼은 disabled와 준비중 문구를 함께 표시한다.
- 경계: 메인, 캘린더, 행사정보, 메인 메뉴의 장르 전달, 원데이/동호회 조회·등록. 수집 허용 장르·기존 DB 분류·관리자의 장르 편집·일정 삭제 정책은 별도 책임이며 변경하지 않는다.
- 호환/롤백: DB 마이그레이션 없음. 기존 Swing 기본값 및 알 수 없는 장르의 Swing fallback 유지. 공개 목록의 활성 여부를 수정하면 공통 선택 로직이 따른다.
- 검증: 기존 taxonomy 테스트 확장 12건, 실제 운영 DB를 읽는 로컬 빌드의 PC 1440px/모바일 390px 메인·캘린더·행사정보 6경로 통과. 비활성 3개 표시/선택 차단, Salsa→Swing 전환, 직접 tango URL fallback, non-draggable 및 브라우저 오류 0 확인. 관리자 분류 확장과 공개 제한은 단위검사로 분리 확인했다.

## 일반 회원 이벤트 등록 연결 보완

- 2026-09-11: 이벤트 등록·소유자 편집에도 같은 공개 범위를 사용한다. 일반 회원의 세부 장르 필터와 상위 등록창의 강제 스윙 복원에 남은 하드코딩만 공통 scopeOptions/normalizeVisibleDanceScope로 교체한다.
- 관리자용 전체 장르 권한, 신규 기본 스윙, 알 수 없는 값 fallback, 기존 로그인/소유권 저장 경계는 유지한다. 새 DB·필드·등록 구조를 추가하지 않는다. 공개 장르가 바뀌면 이 두 경로도 같은 기준을 따른다.
