# 정규 소셜 90일 롤링 캘린더

## 상태

2026-07-26 적용 결정.

## 배경

소셜 공지는 매주 반복되지만 기존 수집기는 날짜가 명시된 포스트만 후보로 저장했다. 그 결과 DJ 공지나 특별행사가 아직 게시되지 않은 미래 주에는 실제로 운영되는 정규 소셜이 캘린더에서 사라졌다.

## 결정

- 최근 여러 주의 공식 공지로 요일·장소가 확인된 정규 소셜만 규칙으로 관리한다.
- 오늘부터 90일 동안 규칙별 개별 `events` 일정을 결정론 ID로 생성한다.
- 일반 행사·강습·워크숍은 기존 수집 방식을 유지하며 반복 생성하지 않는다.
- 같은 날짜와 장소에 실제 수집·등록된 소셜이 있으면 실제 일정이 기본 일정을 대체한다.
- 휴무·취소 후보가 수집되면 해당 출처 규칙의 그 날짜 기본 일정을 생성하지 않거나 제거한다.
- 자동 생성 일정에는 `automation.generated_by`, `rule_id`, `source_id`를 기록해 수동 일정과 구분한다.
- 90일 범위 밖이거나 지난 자동 생성 일정은 다음 조정 때 정리한다.

## 안전장치

- 월간·격주·비정기 소셜은 정규 규칙에 포함하지 않는다.
- 자동 생성 일정은 이미지가 있는 기존 장소/소셜 일정을 템플릿으로 사용한다.
- 수집된 실제 일정과 휴무가 기본 일정보다 우선한다.
- 작업은 동일 ID로 반복 실행할 수 있어 중복을 만들지 않는다.
- Cron 토큰이 없거나 일치하지 않으면 운영 실행을 거부한다.
