# 2026-09-29 — 캘린더 전체 보기와 날짜 이동의 소유권

사용자 요청으로 캘린더의 전체/소셜&행사/강습 선택을 제거한다. CalendarPage가 모든 보기의 분류 값을 `all`로 소유한다. 기존 공개 category URL은 주소 호환을 유지하되 분류를 좁히지 않는다. 장르 선택과 캘린더/리스트/지도 선택은 유지한다.

상세의 날짜 이동은 표시된 일정에서 기존 날짜 유틸리티로 구한 날짜를 전달한다. 행사 ID의 재조회·일회성 DOM 카드 검색은 날짜 이동의 전제조건이 아니다. CalendarPage는 기존 데이터/레이아웃 완료 콜백에서 날짜 셀로 스크롤하며, 대기 날짜 ref는 이 화면 안에서만 소유한다. 기존 ID 딥링크는 상세 열기 호환을 유지하고 동일한 날짜 배치 완료 경로를 사용한다. 라우트 변경 시 오래된 응답/타이머를 무효화한다.

DB·스키마·알림 원장 변경은 없다. 롤백은 UI 소스와 기존 배포 entry 복원으로 가능하다. 검증 결과와 배포 식별자는 ISSUE_LOG에 기록한다.
