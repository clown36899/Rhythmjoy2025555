# 근거 기반 2단계 AI 소셜 수집

- 날짜: 2026-08-14
- 상태: 채택, 로컬 구현·검증 완료, 운영 미배포
- 대체 범위: `2026-08-11-deterministic-ingestion-checkpoints.md`의 자동등록 후보에 AI 승인을 요구하지 않는 결정

## 배경

고정 수집 경로와 결정 규칙은 원문 접근, 날짜 후보, 중복, 과거 일정, 제외 소스를 안정적으로 통제한다. 그러나 여러 포스터가 한 게시물에 붙거나 날짜·DJ·장소가 이미지 레이아웃으로 연결되는 경우에는 정규식 예외를 추가하는 방식만으로 완전한 해석을 유지하기 어렵다. 반대로 AI만으로 검색·등록을 맡기면 출처 범위가 흔들리고 일부 날짜 누락, 추천 이미지 혼입, 환각 근거를 결정적으로 차단하기 어렵다.

## 결정

1. 공식 수집 경로, 원문 다운로드, 날짜 후보 생성, 출처 식별, 과거·제외 정책, 중복 판정은 결정 규칙이 담당한다. AI가 임의의 인터넷 원문을 대신 찾거나 수집 경로 밖의 외부 목록을 등록 근거로 사용하지 않는다.
2. Naver 카페의 게시판 메뉴처럼 같은 도메인·카페 안에서도 운영 주체와 장소가 다른 경로는 독립 수집원 ID로 보존한다. 후보의 명시적 수집원 ID가 URL 기반 추정보다 우선한다.
3. 자동등록 가능성이 있는 비정형 소셜은 첫 AI가 원문 텍스트와 원본 첨부 이미지 최대 3장을 함께 읽어 날짜별 세션, 장소, 전체 DJ, 정확 인용, 1부터 시작하는 근거 포스터 번호를 구조화한다.
4. 결정 규칙이 찾은 날짜 후보를 첫 AI가 일부만 반환하면 결과를 승인하지 않는다. 이미 검증된 세션은 보존하되 누락 날짜만 더 강한 모델로 다시 검사하고, 전체 날짜 범위가 근거와 일치할 때만 하나의 추출 결과로 합친다.
5. 수집기는 AI가 고른 근거 포스터를 해당 세션의 대표 이미지로 사용하고 장소·제목은 표준값으로 정규화한다. AI가 만든 자유 형식 제목은 자동등록 제목의 권위 원본으로 사용하지 않는다.
6. 모든 자동등록 후보는 별도 2차 AI가 같은 저장 원문과 원본 포스터를 독립 검증한다. 날짜, 활동, 장소, DJ 전체가 수집 후보와 일치하고 각 필드의 정확한 인용이 원문 또는 보이는 포스터에 있으며 신뢰도가 0.98 이상이어야 한다.
7. 소셜 DJ가 비어 있는 경우는 원본 포스터가 첨부되고 첫 AI가 DJ 미공지를 명시적으로 확인하며 2차 AI와 서버가 날짜·장소·소셜 근거를 다시 확인한 경우에만 허용한다. 일반 텍스트 후보의 DJ 누락은 계속 차단한다.
8. 첫 AI의 일부 날짜 누락, 이미지 부재, AI 불가·오류·시간 초과, 2차 AI 불일치, 서버 근거 불일치는 모두 자동등록 실패로 닫는다. 후보를 임의 보완하거나 외부 목록 값으로 채우지 않는다.
9. 일정 시각은 이 흐름에서 추출·저장하지 않는다. 날짜, 장소, 활동과 DJ만 자동등록 계약에 포함한다.

## 운영 경계와 비용

- AI는 고정 경로의 모든 글에 무조건 실행하지 않고 소셜 표지, 날짜 후보, 원본 이미지 또는 DJ 표지가 있는 후보에만 실행한다.
- 다중 날짜 재검사는 누락이 확인된 날짜에만 수행한다. AI가 실행되는 게시물에는 모델 호출 예산을 포함한 별도 처리 제한시간을 적용하며 전체 수집 실행 예산은 그대로 유지한다.
- 자동등록 전 두 번의 AI 호출은 비용과 지연을 늘리지만, 정규식 예외의 무한 증가와 잘못된 자동등록보다 정확성과 감사 가능한 근거를 우선한다.
- 강습·모집·출처 밖 일정과 근거가 불완전한 일정은 기존처럼 수동 검토 경계를 유지한다.

## 검증

- 수집 표준 검사와 AI 추출·서버 등록 회귀 테스트 43개 통과
- 축약 날짜 전체 범위 강제, 원본 이미지 없는 포스터 전사 차단, DJ 없는 소셜 이중 검증, 영문 장소 별칭, 세션별 포스터 번호, 서버의 정확 인용 재검증 확인
- 해피홀 공식 다중 포스터 원문의 건조 실행에서 2026-08-14 `메이저`와 2026-08-15 `유광`을 분리하고 서로 다른 근거 포스터를 선택함
- 2026-08-15 후보와 선택된 유광 포스터의 독립 2차 검증에서 `register`, 신뢰도 `0.99`, 오류 0건 확인
- 운영 데이터 쓰기와 배포는 수행하지 않음
