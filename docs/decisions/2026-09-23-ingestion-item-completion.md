# 수집 완료 항목과 실패 항목의 재시도 분리

- 날짜: 2026-09-23
- 상태: 로컬 자동 실행기에 적용·검증 완료. 예약 빈도는 변경 전으로 복원했다.

사용자 의도는 횟수 축소가 아니라 수집이 끝난 항목을 다시 처리하지 않는 것이다. 이전 빈도 축소는 잘못된 해석이므로 철회한다. 기존 진행 기록은 Instagram URL 단위 완료와 출처 단위 잔여 목록뿐이었다. Instagram 한 글의 실패가 같은 출처 묶음 전체의 완료 기록을 막았고, 카페 글에는 본문 단위 완료 비교가 없었다.

기존 `ingestion-progress.mjs`와 우선순위/장르별 동일 진행 파일이 계속 단일 소유자다. `completedItems`를 추가해 출처별 문서 내용 지문과 개별 후보 지문을 보관한다. 기존 URL 목록만으로는 카페의 같은 URL 내용 변경과 한 글의 여러 일정 중 일부 성공을 표현할 수 없어 이 정보가 필요하다. 별도 DB·큐·등록 경로는 만들지 않는다.

문서 읽기와 내용 변경 확인은 기존 공식 브라우저 경로로 수행한다. 내용/출처 정책이 같은 완료 문서는 AI 추출 전에 건너뛴다. Instagram의 기존 완료 URL 건너뛰기는 유지하며 당일 미확정 출처라는 이유만으로 성공한 최근 글 두 개를 강제 재분석하지 않는다.

후보는 실제 저장 또는 확인된 중복 처리 결과를 기록한다. 자동 등록을 시도했다면 등록 실패는 완료로 기록하지 않는다. 성공 후보는 다음 후보 전에 기존 진행 파일에 저장하므로 다른 후보의 실패·시간 초과·재시작이 성공을 되돌리지 않는다. 검수 대기로 정상 저장한 후보와 자동 등록 실패는 구분한다.

문서는 자기 판독과 자식 후보가 모두 처리된 경우에만 완료된다. 다른 글이 실패해도 성공한 문서와 Instagram URL 기록은 남긴다. 일부만 성공한 문서를 재판독할 때도 성공 후보의 재심사·재저장은 건너뛴다. 공개 등록 대조 실패는 해당 문서와 실패 후보만 다시 열고 성공한 형제 후보를 지우지 않는다. 관리자 삭제/휴무/중복/원문 근거 보호는 유지한다.

레거시 파일은 새 항목 기록을 빈 값으로 읽으며 기존 Instagram 완료 기록과 잔여 출처를 보존한다. 카페에는 과거 문서 지문이 없으므로 기존 글 전체를 소급 완료로 추정하지 않는다. 처음 정상 확인된 내용부터 기록한다. 새 글 탐색 및 카페 본문 변경 확인을 위한 접근과 AI·저장 재처리는 별개다.

서버 스키마·마이그레이션·운영 DB 수정은 없다. 롤백은 실행기/진행 기록 모듈을 되돌리는 방식이며 새 필드는 구버전이 무시한다. 그 경우 완료 재처리 억제는 약화되지만 실제 후보·공개 일정은 삭제하지 않는다.
