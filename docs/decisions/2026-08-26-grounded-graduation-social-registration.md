# 근거가 완결된 공식 졸공의 자동등록

- 날짜: 2026-08-26
- 상태: 채택·로컬 구현

## 배경

공통 졸공 정규화는 명시적 졸업공연·졸업파티를 `social/졸공`, `group_id=2`와 졸공 표시값으로 변환한다. 그러나 자동등록 경계는 모든 특수행사를 일괄 차단해, 공식 출처의 정확한 날짜·장소·원본 이미지가 있는 졸공도 후보 원장에만 남았다.

## 결정

1. 새 테이블·큐·상태값을 만들지 않고 기존 `scraped_events` 후보 원장과 자동등록 API를 재사용한다.
2. 자동등록에 등록된 공식 출처, 정확한 미래 날짜, 검증 장소, 원본 이미지, 명시적 졸업공연·졸업파티 근거가 모두 있는 후보만 공통 졸공 정규화 결과로 등록한다.
3. 졸공의 `DJ 졸공` 표시는 원문 DJ 근거가 아니라 기존 캘린더 분류용 표시값이므로, 서버는 명시적 졸공 근거를 재검증한다.
4. 이미지가 없거나 출처가 수동 전용인 졸공, 일반 행사·대회·컴피티션은 기존 수동 검수 경계를 유지한다.
5. 같은 원문·날짜 후보 ID, 운영 일정 중복 검사, 실제 일정 ID가 생긴 뒤에만 후보를 완료 처리하는 불변조건을 유지한다.
