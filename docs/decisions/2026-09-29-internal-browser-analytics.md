# 내부 브라우저 점검의 통계 제외

- 날짜: 2026-09-29
- 상태: 채택

자체 수집기는 전용 인증 API를 호출하므로 방문 통계를 만들지 않는다. 알려진 봇·webdriver·관리 경로·관리자 기기 제외도 이미 있다. 그러나 로그인하지 않은 내부 점검 브라우저가 일반 UA로 공개 화면을 열면 일반 방문과 구분할 입력이 없었다.

내부 점검은 `https://swingenjoy.com/?analytics=internal`로 시작한다. 다른 화면은 기존 query에 `analytics=internal`을 추가한다. 자동화 도구도 첫 사이트 진입에 이 주소를 사용한다. 앱이 sessionStorage의 `rhythmjoy:analytics-internal`을 설정하며 같은 탭의 페이지 이동·새로고침에서 제외를 유지한다. 새로운 일반 방문 검증은 별도의 깨끗한 브라우저 컨텍스트에서 수행하고 전송 요청을 가로채 운영 원장에 가짜 방문을 쓰지 않는다. 탭 복제/열기는 브라우저에 따라 sessionStorage를 복사할 수 있으므로 깨끗한 컨텍스트와 같다고 간주하지 않는다.

판정의 소유자는 기존 analyticsGuards다. 기존 세션/클릭/PWA 전송, GA, 콘텐츠 조회수의 허용 검사에 같은 판정을 연결한다. 대기 중 클릭 및 인증 조회 후 콘텐츠 조회수도 보내기 직전에 다시 검사한다. 관리자 전용 권한이나 인증에는 영향을 주지 않는 통계 opt-out이다.

기존 관리자 localStorage 차단은 로그인된 관리자 기기를 지속적으로 제외하는 별도 책임이다. 이를 내부 브라우저 표시에 재사용하면 관리자와 자동화의 의미 및 다른 탭까지 영향을 주는 수명이 섞이므로, 탭 단위 표시에 한해 위 sessionStorage 키를 사용한다. 새로운 DB 필드·테이블·큐·서버 집계기는 없다. 저장소가 차단되면 현재 문서는 메모리로 제외를 유지하며, 이후 전체 페이지 진입에도 명시 주소를 사용해야 한다.

정상 방문, 기존 관리자 기기 제외, 0631571a의 관리자 콘텐츠 1회 조회 정책, 기간 밖 관리자 연결, 확정된 과거 보고서는 유지한다. 명시 표시 없는 미탐지 자동화까지 차단했다고 주장하지 않는다. 내부 자동화에는 진입 주소를 지정해야 한다.

이번 배포는 프런트만 교체한다. 실패 시 직전 프런트 파일 복구로 되돌릴 수 있으며 서버/DB 마이그레이션은 없다. 키가 남아 있어도 구버전은 읽지 않는다. 검증은 일반/내부, 이동/새로고침, 저장 실패, 지연 전송, 기존 관리자 조회수 및 보고서 제외 경계를 포함한다.
