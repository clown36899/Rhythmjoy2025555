# 악기 분리 플레이어 샘플 경계

- 날짜: 2026-09-03
- 상태: 샘플 구현
- 경로: `/stem-lab`

## 결정

기존 `/groove-lab`은 리듬 학습 도구로 유지하고, 악기 분리 결과를 조작하는 경험은 별도 `/stem-lab`에서 검증한다. 현재 단계에서는 업로드나 AI 분리 작업을 추가하지 않고, 처음부터 분리해 합성한 네 개의 짧은 스템을 하나의 공통 시간축으로 재생한다.

새 페이지는 메인 콘텐츠 카드에 노출하지 않는다. 하단 `MENU`를 펼쳤을 때 보이는 아이콘 메뉴에만 기본 비고정 항목으로 추가한다.

## 이유와 경계

- 기존 Web Audio 합성기와 콘트라베이스 샘플을 재사용한다.
- 네 스템은 같은 시작 시각과 반복 길이를 사용하며, ON/OFF·솔로·개별 음량은 재생 위치를 바꾸지 않고 각 출력 게인만 조절한다.
- 페이지에 실제 AI 분석 결과가 아님을 표시해 분리 품질 검증과 플레이어 조작 검증을 혼동하지 않는다.
- 실제 음원 업로드, GPU 분리 작업자, 작업 상태·보관·삭제 정책은 이번 샘플 범위에서 제외한다.

## 검증

루프 경계와 음소거·솔로 판정은 단위 테스트로 확인하고, 실제 브라우저에서 네 트랙의 동시 시작, 조작 중 플레이헤드 유지, 모바일 화면을 확인한다.
