# 후보 자체 근거 우선 분류와 자동등록 실패 재수집

- 날짜: 2026-08-28
- 상태: 채택·로컬 구현

## 배경

네오스윙 141기 강습 모집글은 8월 30일 강습 시작과 10월 25일 졸업파티를 함께 안내했다. 수집기는 본문 어딘가의 `파티`와 `졸업파티`를 현재 후보의 종류로 사용해 8월 30일 강습을 `social/졸공`, DJ `졸공 141회`로 바꿨다. 저장 중복 검사가 오등록은 막았지만 자동등록 완결성 실패는 출처 체크포인트 저장 뒤에 확인돼 같은 게시물이 다음 실행에서 자동 재검사되지 않았다.

## 기존 구현 판정

일부 있음. 공통 졸공 정규화, Instagram 제목 추출, 공식 출처별 자동등록 정책, 98% AI 검증, 서버 재검증, 중복 차단과 출처별 체크포인트가 이미 존재했다. 새 큐·상태값·출처 예외 없이 기존 공통 판정기와 체크포인트 원장을 재사용한다.

## 결정

1. 후보 제목 또는 명시 분류가 강습·수업·모집·판매이거나 댄스 종목과 입문·초급·중급·베이직 조합이면 본문의 후속 졸업파티를 현재 후보의 졸공 근거로 승격하지 않는다.
2. 후보 자체 제목·종류에 졸업공연·졸업파티가 명시됐거나 일반 행사 후보에서 원문 졸공 근거가 확인된 경우에는 기존 `social/졸공` 정규화와 공식 졸공 자동등록 경계를 유지한다.
3. 자동등록 완결성 검증에 실패한 Instagram 게시물 URL만 기존 확인 완료 목록에서 제거해 다음 실행에서 다시 수집한다. 정상 처리 게시물과 처리 가능한 파싱 제외 게시물은 기존 체크포인트를 유지한다.
4. 특정 네오 게시물 ID·날짜·장소 예외를 추가하지 않는다.

## 유지한 불변조건

- 공식 원문, 정확한 미래 날짜, 검증 장소, 이미지와 98% AI 근거를 사용하는 기존 자동등록 기준을 유지한다.
- 실제 졸공과 일반 소셜의 분류·표시, 운영 일정 중복 차단, 등록 완료 뒤 후보 완료 처리 순서를 유지한다.
- 직접 DB 수정이나 운영 일정 삭제를 하지 않는다.

## 검증

- 수집 표준 검사 통과
- 관리자·캘린더·서버 대상 Vitest 49건 통과
- 실제 네오 최신 게시물 9건 dry-run: 강습 7건, 과거 휴무 예외 1건, 과거 졸공 1건은 미래 후보 없음, 잘못된 소셜 후보 0건, 자동등록 완결성 기대·누락 0건
- 대상 ESLint와 변경 공백 검사 통과
