# 무료 혜택 대상과 행사 회차 구분

- 날짜: 2026-10-04
- 상태: 채택, 운영 데이터·서버·프런트·Mini PC 수집기 반영 완료 (b1ecce89, version 1791082564635)

무료 강습이 포함된 유료 소셜은 혜택 목록에 유지하되 설명 첫머리에 강습만 무료이고 소셜 입장료는 별도임을 안내한다. `free_event`는 기존 혜택 종류이며 소셜 전체의 무료 입장을 뜻하지 않는다. 공개 배지는 `무료 혜택`으로 표시한다. 실제 무료 입장·참여가 명시된 경우에는 강습 한정 안내를 붙이지 않는다.

같은 주간 공지에 여러 날짜가 있으면 해당 회차에 연결된 원문 구간만 혜택 분류의 근거로 사용한다. 금요일의 무료 강습을 일요일 소셜에 복사하지 않는다. 기존 날짜/DJ 및 주간 공지 파서를 재사용하며, 분류와 설명 생성 책임은 `scripts/ingestion/candidate-utils.mjs`에 유지한다. 원문 `extracted_text`는 보존한다. 기존 description을 자동등록이 사용하지 않았던 연결만 보완한다. 새 데이터 필드나 별도 무료 소셜 이벤트는 만들지 않는다.

혜택 목록은 기존 `isPastBenefitEvent`를 사용해 종료된 항목을 숨긴다. 오늘, 남은 다회차, 종료일 없는 상시 항목은 유지하며 기록을 삭제하지 않는다. 별도 시간 표시를 추가하지 않고 원문 설명의 시간은 그대로 둔다.

기존 backfill 복구 도구에서 검토된 후보 ID를 지정해 공개 이벤트도 함께 정정할 수 있다. 연결 ID·출처·날짜·완료 상태 확인, 기존 이벤트 변경 잠금, 행 잠금, 동시 변경 검사, 원본 백업과 단일 트랜잭션을 사용한다. 스키마 마이그레이션은 없다. 코드 롤백과 데이터 복구는 별개이며, 필요 시 백업을 현재 레코드와 대조해 복구한다. 코드 롤백으로 잘못된 무료 분류를 자동 복원하지 않는다.

서버 반영은 기존 `deploy:cafe24 -- --server-patch <base>`에 기존 `scripts/ingestion/*.mjs` 파일도 포함해 수행한다. 신규 모듈 금지·충돌 중단·기준 해시 검사·백업·롤백·버전 마지막 공개 규칙은 그대로다. 프런트는 기존 `--frontend-only`, 실제 수집기는 기존 Mini PC staged runtime 절차를 사용한다.
