# 재즈 스윙의 기본 청취 단위를 리듬 섹션으로 변경

- 날짜: 2026-08-31
- 상태: accepted

## Context

Groove Lab에는 라이드, 2·4 하이햇, 워킹 베이스와 Four-to-bar 기타가 각각 구현되어 있었지만 재즈 스윙 계열의 첫 화면은 라이드 단독 프리셋이었다. 베이스와 기타를 선택하면 연구 의도대로 균등한 네 박만 들리기 때문에, 사용자는 개별 악기 역할을 재즈 스윙 전체 결과로 오해할 수 있었다.

Friberg & Sundström의 템포별 스윙 비율은 드러머 라이드 측정 경향이며 모든 악기의 박을 변형하는 보편 공식이 아니다. Butterfield의 라이드 분석과 워킹 베이스·Freddie Green 기타 자료를 함께 보면 스윙의 교육용 기본 청취 단위는 롱–숏 라이드와 안정된 네 박이 결합된 리듬 섹션이어야 한다.

## Decision

- 기존 라이드·하이햇·베이스·기타 이벤트와 음색을 합성하는 `재즈 스윙 앙상블`을 재즈 스윙 계열의 첫 프리셋이자 페이지 기본값으로 둔다.
- 템포별 비율은 라이드 스킵 노트에만 적용하고 베이스와 기타의 4분음표 시작점은 유지한다.
- 기존 단독 악기 프리셋은 분석과 파트 연습을 위해 보존한다.
- 앙상블 악보는 악기별 점이나 레인으로 나누지 않고 선택된 모든 사건의 리듬 기능을 단일 시간축에 음표로 표시한다. ON과 OFF 음표 좌표는 실제 예약 onset 비율을 공유하고, 2·4 백비트와 OFF 강세를 별도 기호로 표시한다. 단독 악기 타임라인의 기존 위치 병합은 유지한다.
- `adaptive`와 `triplet` 표시는 각각 `연구 기반 라이드 비율`, `고정 2:1 셋잇단`으로 바꿔 실제 스윙 전체와 고정 셔플 격자를 구분한다.
- 무작위 humanize나 전 악기 공통 미세타이밍은 추가하지 않는다.
- 기본 리듬 섹션은 드럼 시간축과 워킹 콘트라베이스로 두고, Charleston 피아노와 Four-to-bar 기타는 독립 선택 레이어로 기본 OFF 처리한다.
- 상단 악기 프리셋 카드를 드럼·베이스·피아노·기타의 다중 선택과 전체 켜기/끄기의 유일한 조작부로 사용하며 별도 하단 믹서를 두지 않는다.
- `스윙 핵심 가이드`는 합주 악기가 아니라 모든 박의 늦고 강한 OFF와 2·4 백비트를 분리해 듣는 교육용 클릭이다. 라이드의 측정 기반 비율을 위치 기준으로 재사용하되 실제 라이드는 표준 `1 · 2-& · 3 · 4-&`를 유지한다.

## Consequences

재즈 스윙 진입 시에는 앙상블 관계가 바로 들리며, 사용자는 단독 워킹 베이스의 균등한 네 박을 스윙 부재로 오해하지 않게 된다. 프리셋은 28개에서 29개로 늘어난다. 타이밍 엔진과 데이터 소유자는 늘리지 않고 기존 이벤트 필터를 재사용하며, 워킹 베이스만 CC0 콘트라베이스 피치카토 실음 자산을 사용하고 로드 실패 시 기존 합성 경로로 복구한다.
