# 정기 발견과 미완료 재시도 구분

- 날짜: 2026-09-23
- 상태: **예약 축소 철회**. 사용자 의도를 잘못 해석했다. 같은 날 후속 정정으로 저장소/설치본 모두 기존 31개 예약 및 전체 확인 시간대로 복원했다. 아래는 철회한 결정의 기록이다. 출처별 미완료 선택은 유지하며 실제 해결은 [항목별 완료 기록](2026-09-23-ingestion-item-completion.md)에 따른다.

사용자는 과도한 반복 수집을 지적하며 미완료 항목만 처리하도록 요청했다. 기존 하루 31개 예약 중 주요 스윙 priority1/2가 26개를 차지했다. 전체 수집 10회는 성공한 출처도 반복했고 보충 실행은 당일 소셜만 좁혀 다른 미완료 출처의 기존 상태를 활용하지 못했다.

기존 LaunchAgent 2개의 예약을 각각 4회로 줄인다. priority1은 08:00·12:30·16:30·20:30, priority2는 09:00·13:00·17:00·21:00이다. 새 공지가 올라오는 것을 확인하기 위한 전체 실행은 각 그룹 아침·저녁에만 유지한다. 중간 실행은 기존 `remainingSources`와 당일 미확정 소셜에 해당하는 현재 허용 출처만 선택한다. 완료 출처를 중간 재시도에 덧붙이지 않는다. 출처 단위 재시도이며 같은 미완료 출처 안의 모든 문서가 개별 실패 재시도 대상으로 제한된다는 의미는 아니다.

진행 상태의 소유자는 `ingestion-progress.mjs`, 실행 대상 연결은 `swing-daily-native.mjs`, 예약 소유자는 기존 두 plist다. 새로운 작업이나 상태 필드를 만들지 않는다. 다른 장르/우선순위 진행 상태, 수동 전체 수집, 소스 제외, 공개 기준 조회 실패 시 보류, 실제 등록 근거·중복 판정은 유지한다. 새 공지 발견 지연이 늘어나는 대신 반복 조회를 줄인다.

priority3/4 혜택 각 1회와 살사 3회는 유지하여 총 예약은 하루 13회다. 로그인 복구 없이 반복 실행만 늘리는 것을 정상 복구로 간주하지 않는다. 로그인 실패 등은 기존 미완료 상태에 남긴다. 후속 예약 성공 여부는 별도 실제 결과로 판단한다.

DB 마이그레이션이나 사이트 배포는 없다. 롤백은 두 plist의 이전 시간/환경 복원 및 재로드, 보충 모드 대상 제한 연결 복원으로 가능하며 수집 원장을 초기화하지 않는다.
