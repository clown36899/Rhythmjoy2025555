# 공식 소셜 자동등록 완결성 판정

## 상태

2026-08-27 채택.

## 배경

기존 `swing-daily` 요약은 이번 실행에서 발견·저장·등록한 건수와 단계별 차단을 보여 주지만, 공식 원문에서 확인된 자동등록 대상 일정이 후보와 공개 이벤트까지 모두 연결됐는지는 판정하지 않았다. 따라서 한 후보의 등록 성공만으로 같은 실행 또는 같은 날짜 범위의 다른 누락을 놓칠 수 있었다.

## 결정

자동등록 정책이 `shadow` 또는 `auto`인 공식 소스에서 이미지와 명시적 소셜 날짜가 확인되면 이를 기대 일정으로 기록한다. 제목에서 직접 파악한 일정뿐 아니라 실제로 추출된 이미지 포함 소셜 후보도 같은 기대 원장에 합친다. 각 기대 일정은 후보 준비 상태와 실운영 등록 뒤 공개 이벤트 API를 차례로 대조한다.

실운영 실행은 기대 일정이 후보로 생성되지 않거나, 등록 준비 상태가 아니거나, 날짜·장소·DJ가 일치하는 공개 이벤트를 찾지 못하면 완결성 실패로 종료한다. 건조 실행은 외부 저장을 하지 않지만 저장 직전 2차 AI까지 실행하고 후보 준비 상태를 완결성 결과에 반영한다. 실행 예산 초과와 남은 소스가 있는 경우의 기존 부분 실행 종료 코드 75는 유지한다.

휴무는 기대 활성 일정에서 제외하되 같은 달의 축약 일자를 별도 날짜로 범위화한다. 혼합 공지는 휴무 후보를 보존하면서 다른 활성 날짜의 포스터 추출을 계속한다. 과거 공식 DJ 이름은 OCR 철자 재확인 힌트일 뿐 현재 원문의 증거가 아니며, 현재 포스터가 명확히 뒷받침하지 않으면 등록하지 않는다.

## 불변조건과 영향

- 공식 출처·미래 날짜·장소·이미지·활동·DJ 근거가 모두 맞아야 자동등록한다.
- 휴무, 일반 행사·대회, 수동 출처와 불완전한 포스터는 기존처럼 차단한다.
- 결정론 후보 ID, 중복 판정, 정규 소셜 원장과 Cafe24 API 소유권을 유지한다.
- 새 DB 스키마·테이블·큐·상태값은 추가하지 않는다.
- 완결성 실패는 문제를 숨기지 않고 자동화 실패로 노출하지만, 운영 DB를 직접 보정하지 않는다.
