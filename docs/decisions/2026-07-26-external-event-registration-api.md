# 파트너별 외부 일정 등록 API

- 날짜: 2026-07-26
- 상태: accepted

## Context

외부 사이트 운영자가 자기 사이트에 일정을 등록할 때 Swing Enjoy에도 같은 일정을 한 번에 등록하고 싶어 한다. 외부 원본의 수정·삭제도 동기화하되 여러 집단 사이에 소유권 침범이 없어야 한다.

## Decision

- 등록과 동일 파트너 소유 일정의 전체 수정·삭제를 제공한다. 권한 기준은 내부 이벤트 ID가 아니라 `partner_id + external_id` 소유권이다.
- 파트너마다 독립 API Key를 발급하며 원문 대신 SHA-256 해시를 저장한다.
- `partner_id + external_id`를 고유값으로 사용해 재시도에 의한 중복 일정을 방지한다.
- 분류는 현재 사이트의 `category`별 장르 목록만 허용한다. 파트너별 기본 분류를 둘 수 있지만 새 분류를 자동 생성하지 않는다.
- 외부 API 날짜 입력은 `event_dates` 하나로 통일한다. 단일 일정은 날짜 1개, 개별 날짜 일정은 여러 개를 보내며 연속 기간 방식은 지원하지 않는다. 내부 DB 호환용 날짜값은 서버가 생성한다.
- 관련 링크는 모든 일정에서 필수다. 이미지는 행사·강습·동호회에서 필수지만 소셜은 예외로 하며, 이미지 없는 소셜은 상세 화면의 기존 카카오맵을 사용할 수 있도록 정확한 주소를 필수로 받는다. `scope=domestic`, `show_title_on_billboard=true`는 서버에서 적용한다.
- API 등록은 홈 메인 광고 노출을 보장하지 않는다. 일반 일정과 동일한 비소셜·미래일정·관리자 필터·등록자/장소 중복 제한을 적용한다.
- 이미지를 사용하는 일정은 `upload`와 `url` 두 방식 중 하나를 선택한다. 두 방식 모두 실제 파일을 검사하고 100/300/650/1300px WebP 4종으로 자체 저장한다. 외부 URL은 사설망 DNS와 리디렉션을 차단하고 검증한 공인 IP에 연결을 고정한다.
- 파트너별 호출량 제한과 요청 결과 로그를 저장한다.
- 외부 서버와 브라우저 로그인 세션은 공유하지 않는다. 파트너 Key를 서버 자격 증명으로 사용하고 Swing Enjoy 관리자 세션으로 파트너 중지와 요청 로그 조회를 제어한다.
- 신규 파트너 Key는 반드시 기존 회원 계정에 연결한다. 연결 회원은 API 일정의 내부 소유자이며, 관리자 계정은 키를 발급·중지·재발급하는 통제 주체로 분리한다.
- 관리자 변경 API는 관리자 로그인 세션과 동일 출처를 함께 검증하며, 키 원문은 발급·재발급 응답에서 한 번만 제공한다. 모든 관리자 변경은 별도 감사 로그에 남긴다.
- 이미지 없는 소셜의 주소는 파트너 인증이 필요한 주소 확인 API로 카카오 Local API 후보를 제공하고, 최종 일정 등록 시에도 서버가 다시 확인한 표준 주소만 저장한다.

## Consequences

- 새로운 파트너는 코드 변경 없이 DB 등록과 키 발급만으로 추가할 수 있다.
- 외부 사이트는 비밀 키 보호를 위해 브라우저가 아니라 서버에서 API를 호출해야 한다.
- 파트너가 업로드 API를 사용하면 원본 사이트 이미지 권한이나 URL 수명에 의존하지 않는다.
