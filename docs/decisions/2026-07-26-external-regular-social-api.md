# 외부 API 정규 소셜 반복 규칙과 예외 모델

- 날짜: 2026-07-26
- 상태: 채택

## 결정

기존 `/api/external/v1/events`는 모든 분류의 날짜별 개별 일정 API로 유지한다. 정규 소셜에만 반복 규칙 API와 날짜별 예외 API를 별도로 제공한다.

반복 규칙은 캘린더의 무기한 반복 객체로 저장하지 않는다. 서버가 앞으로 90일의 개별 일정을 생성하고 매일 다시 조정한다. 휴무는 `closure`, DJ·시간·장소 변경은 `override`로 해당 날짜에만 적용한다. 졸공이나 별도 행사는 기존 개별 일정 API를 사용한다.

## 우선순위

1. 공식 날짜별 개별 일정
2. 공식 반복 규칙의 날짜별 예외
3. 수집으로 확인된 변동 정보
4. 공식 반복 규칙
5. 내부 정규 소셜 기본 규칙

같은 장소와 요일에 공식 반복 규칙이 존재하면 내부 기본 규칙을 대체한다. 규칙이나 예외가 변경·삭제되면 그 규칙이 생성한 미래 일정도 다시 생성하거나 제거한다.

수집 후보와 공식 API 일정의 중복은 원본 URL이 같으면 즉시 중복 처리한다. 소셜은 DJ나 제목 표현이 달라질 수 있으므로 날짜·정규화된 장소가 같으면 같은 일정으로 판정하고 공식 API 일정을 유지한다. 행사·강습 등은 한 장소에서 같은 날 여러 일정이 열릴 수 있어 날짜·장소에 제목 유사도까지 결합한다.

## 이유

전 장르 개별 일정 API의 계약을 깨지 않으면서, 정규 소셜 운영자가 매주 동일한 일정을 반복 전송하지 않고 DJ·휴무처럼 실제로 바뀐 날짜만 전송할 수 있게 하기 위함이다.
