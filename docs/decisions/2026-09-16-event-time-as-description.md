# 행사 시간은 설명으로만 안내

- 날짜: 2026-09-16
- 상태: 확정 (사용자 지시)
- 등록·수정·상세에 별도 시작/종료 시간 입력과 표시를 제공하지 않는다. 날짜는 유지한다.
- 퍼온 설명, 직접 작성한 설명, 포스터 속 시간은 그대로 보존한다. 시간 문구를 필터링하거나 추출하지 않는다.
- 기존 SocialScheduleModal 상태/저장 어댑터와 DB 시간 필드는 레거시 호환을 위해 유지한다. 데이터 이관·삭제 없이 표시/입력만 제거한다.
- 기존 EventEditBottomSheet는 폐지한 time 호출을 표시하지 않고 설명 편집을 그대로 재사용한다.
- 소셜 디자인만 변경하며 강습·일반 행사의 기존 디자인과 권한·삭제 확인은 유지한다.
- 검증: 기존 편집 회귀 테스트 확장(폐지된 입력 차단, 설명 시간 원문 보존), 소셜 분류 테스트, 빌드 및 DB 연결 화면 확인.
- 롤백: 해당 UI 변경만 되돌리면 된다. 스키마 변경이나 신규 데이터 소유자 없음.
