# 알림 시간 정보 미제공 원칙

- 날짜: 2026-08-05
- 상태: 채택

## 배경

알림함 카드가 알림 수신 시각을 항상 표시했고, 오늘 일정 요약은 첫 일정의 시작 시각을 본문과 미리보기 데이터에 포함했다. 알림에서 시간 정보를 제공하지 않는 사이트 운영 원칙과 맞지 않았다.

## 결정

1. 사이트의 인앱 알림함, Web Push 제목·본문, 알림 미리보기 데이터에는 시간 정보를 제공하지 않는다.
2. 제공하지 않는 시간 정보에는 행사 시작 시각과 알림 발송·수신 시각이 모두 포함된다.
3. 날짜와 장소는 알림 문맥을 위해 계속 제공할 수 있다.
4. 정렬, 만료, 전송, 읽음 상태 처리에 필요한 타임스탬프는 사용자에게 노출하지 않고 내부에서만 유지할 수 있다.
5. 과거 알림 데이터에 수신 시각이나 일정 시각이 남아 있어도 알림 UI는 이를 렌더링하지 않는다.

## 결과

알림 카드는 제목, 설명, 날짜, 장소만 표시한다. 오늘 일정 요약의 생성 경로도 일정 시각을 본문이나 항목 데이터에 넣지 않는다.
