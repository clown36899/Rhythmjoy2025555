# 자유게시판 비공개 글 열람 경계

- 날짜: 2026-08-13
- 상태: 채택, 운영 반영·검증 완료

## 배경

자유게시판은 건의 작성에만 비공개 선택을 기본 제공하고 일반 글쓰기에서는 선택란을 숨기고 있었다. `is_hidden` 글을 목록과 상세 화면에서 가리는 클라이언트 로직은 있었지만, 범용 조회 API가 직접 요청에도 같은 열람 경계를 강제해야 비공개라는 사용자 약속을 지킬 수 있다.

## 결정

1. 로그인 사용자는 자유게시판 글 작성과 본인 글 수정에서 공개·비공개를 선택할 수 있다. 일반 글은 공개가 기본이고 건의 작성은 비공개가 기본이다.
2. 비공개 상태인 자유게시판 글의 전체 내용은 작성자와 관리자만 볼 수 있다.
3. 관리자는 게시글 상세의 기존 숨기기·해제 기능으로 같은 비공개 상태를 관리할 수 있다.
4. 권한 없는 사용자에게는 목록 페이지 순서와 개수 유지를 위해 `id`, 생성일, 머릿말, 공지·정렬 상태와 반응 통계만 반환한다. 제목, 본문, 작성자 정보, 소유자 ID와 이미지는 반환하지 않는다.
5. 비공개 행의 비식별화는 호출자가 보낸 필터보다 먼저 수행한다. 따라서 비공개 제목·본문·작성자 값을 필터 조건으로 시험해 존재 여부를 추측할 수 없다.
6. 작성자 판정에는 현재 사용자 ID와 마이그레이션 과정에서 보존한 레거시 사용자 ID를 모두 사용한다.

## 결과

비공개 글도 목록 페이지의 위치는 유지되지만 권한 없는 사용자는 `숨김 글이 있습니다` 수준의 자리 표시 정보만 받는다. 작성자와 관리자는 목록 및 상세에서 정상적으로 글을 열 수 있고, UI 우회나 범용 API 직접 호출로도 비공개 내용이 노출되지 않는다.

커밋 `57f6a439`를 운영 배포했다. 비로그인 운영 API에서 비공개 글 3건의 보호 필드가 제거되고 공개 글 제목은 정상 유지되는 것을 확인했으며, 운영 서버의 보안 모듈과 편집기 자산 해시는 로컬 배포 산출물과 일치했다.
