# 결정 규칙 우선 수집과 게시물 체크포인트

- 날짜: 2026-08-11
- 상태: 채택
- 대체 범위: `2026-08-10-ingestion-quality-and-resume.md`의 AI 혜택 저장 조건과 고정 게시물 확인 창

## 배경

일일 수집의 목적은 등록된 고정 경로의 신규 게시물을 놓치지 않고, 한 게시물 안의 날짜별 내용을 소셜·강습/모집·혜택으로 분리하는 것이다. 날짜·장소·DJ가 원문에 명확한 소셜도 AI 응답을 다시 통과해야 했기 때문에 AI 오류나 재검토가 자동등록을 멈췄다. 혜택 역시 AI를 호출할 수 없다는 이유만으로 후보 자체가 사라졌다. 최신 N개만 반복 확인하는 방식에는 신규 게시물이 확인 창 밖으로 밀리는 누락 가능성도 있었다.

## 결정

1. 자동등록 가능한 소셜은 원문 안의 날짜별 근거에 날짜, 장소, DJ, 소셜 활동 표지가 모두 있어야 한다. 수집기와 서버가 같은 결정 규칙으로 이를 각각 검증한다.
2. 이 결정 근거가 완전한 소셜에는 AI 승인을 요구하지 않는다. AI는 비정형 또는 애매한 후보의 보조 판정으로만 사용한다.
3. 강습·모집은 자동등록하지 않고 관리자 후보에 보존한다.
4. 무료·할인·정기권 등 혜택은 결정 규칙을 통과하면 관리자 후보에 보존한다. AI가 원문 근거로 명시적으로 거절한 경우만 제외하며, 오류·불가·재검토는 후보 유실 사유가 아니다.
5. 연도 없는 날짜는 수집 시점이 아니라 원문 게시일에 가장 가까운 유효 연도로 정한다. 서버는 원문 게시일에서 비현실적으로 먼 일정과 오래된 혜택 원문을 다시 차단한다.
6. 각 Instagram 소스는 최근에 확인 완료한 게시물 URL을 별도로 보존한다. 다음 실행은 최신 고정 개수가 아니라 아직 확인하지 않은 URL부터 처리한다.
7. 게시물 체크포인트는 스크랩 성공만으로 확정하지 않는다. 해당 소스에서 후보 저장과 자동등록 요청까지 오류 없이 끝났을 때만 확인 완료로 기록해 실패한 게시물을 다음 실행에서 다시 시도한다.
8. 생성된 정규 소셜과 같은 날짜·장소에 실제 게시물 소셜이 들어오면 동일한 전체 검증을 통과한 실제 일정으로 교체한다.

## 운영 경계

- 소스 목록과 수집 위치는 `collection-registry.mjs`에 등록된 고정 경로를 사용한다.
- 인터넷 임의 검색은 일일 고정 경로 수집의 대체 수단이 아니다.
- 후보 저장은 Cafe24 수집 API, 자동등록은 전용 등록 API를 사용하며 수집기는 일정 테이블을 직접 쓰지 않는다.
- 대관 가능일정, 과거 날짜, 종료 후기, 은퇴·제외 소스는 기존 결정 규칙으로 계속 차단한다.

## 검증

- 수집 표준 테스트의 게시일 연도 정렬, 소스별 미확인 URL 선택·병합, 과거 혜택 서버 차단 사례
- AI 혜택 보존 및 근거 기반 거절 테스트
- 서버의 경성홀 날짜별 소셜 자동등록과 생성 정규 소셜 교체 테스트
- 경성홀 실제 고정 경로 무저장 실행에서 강습 2건, 날짜·DJ가 명확한 소셜 1건, 대관 공지 제외 확인
