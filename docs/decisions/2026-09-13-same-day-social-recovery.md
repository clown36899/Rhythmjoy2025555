# 당일 미확정 소셜 재수집

- 날짜: 2026-09-13
- 상태: 구현·회귀검증 완료, 운영 설치 후 갱신.
- 기존 구현 판정: 일부 있음. 별도 작업 큐/DB 상태/수집기는 추가하지 않는다.

## 증상과 원인

당일 해피홀이 정규 생성본 DJ 미정으로 남았다. 08:00 실행은 네오와 해피홀 글을 이미 확인한 URL로 건너뛰었다. `selectUnseenInstagramPosts`의 체크포인트(dcd369e0)는 반복 읽기 비용과 동일 글 중복 처리를 방지하는 목적이다. `reconcileExpectedAutomaticSocials`는 이번 실행에서 발견한 소셜만 검증하므로, 후보 자체가 나오지 않은 누락은 기대 건수 0으로 끝났다. 실패 원장 재개(10e7a762)와 저녁 예약(bd0aebe8)은 이미 존재하지만 이 누락 판정과 연결되지 않았다.

## 결정과 소유권

- `ingestion-progress.mjs`에서 공개 당일 정규 생성본의 미확정 상태를 허용 소스 레지스트리에 대조한다. 기본 생성본이 없으면 반복 규칙으로 추정 생성하지 않는다. 관리자 삭제·공식 휴무/override·이미 등록된 동일 날짜/장소 소셜은 재수집 대상이 아니다.
- native 실행 시작에 해당 소스를 기존 잔여 소스보다 우선한다. Instagram은 소스별 실행당 한 번, 현재 보이는 확인 완료 글 최대 2개를 기존 묶음에 다시 포함한다. 새 글 처리·묶음 제한·전체 20분 예산·접근 실패 회로·다음 실행 재시도 규칙은 유지한다.
- 실행 후 공개 API를 다시 대조한다. 미확정 소스 및 자동등록 결과 누락은 기존 `remainingSources`에 남긴다. 확인 실패나 응답 한도 도달은 성공 완료로 처리하지 않는다. 원문이 없거나 불명확해도 추정 등록하지 않는다.
- 기존 priority1 예약은 08:00/12:30/16:30/18:30/20:30, priority2는 09:00/13:00/17:00/19:00/21:00(KST). Instagram과 카페 소셜 모두 같은 구현을 사용한다. 각 실행은 20분 예산, 예약 간 30분 간격과 기존 전역 잠금을 유지한다. 혜택 priority3/4는 변경하지 않는다.
- 날짜 기반 수집 정책, 공식 원문·DJ·장소 근거, 기존 AI 98% 문턱, 이미지 선택 정책, 결정론 ID와 서버 중복/관리자 삭제 차단은 변경하지 않는다. AI의 confidence는 실측 전체 정확도가 아니다.

## 적용·롤백·제약

Mac의 기존 수집 작업 폴더와 기존 LaunchAgent 2개에만 설치한다. 서버 API/DB/웹 번들은 변경하지 않으므로 이 작업을 위해 웹사이트를 재배포할 필요는 없다. 코드와 plist를 되돌려 동일 LaunchAgent를 다시 로드하면 롤백할 수 있으며 기존 체크포인트 형식은 그대로 호환된다. 별도 daemon/자동화/큐가 생기지 않는다.

Mac이 켜져 있고 로그인 세션·네트워크가 유지되어야 예약이 실행된다. 화면 잠금은 headless 수집과 별개지만 절전·전원 종료나 Instagram 접근 차단까지 해결됐다고 주장하지 않는다. 상위 2개 확인 완료 글 밖의 오래된 공지를 무제한 재탐색하지 않는다. 공식 공지가 없는 날짜는 DJ 미정으로 남겨 다음 예약에서 확인한다.

## 검증과 실제 복구

- 기존 ingestion standards에 당일/다른 날짜, 관리자 삭제 후 부재, 휴무/override, 확정 DJ/등록 일정, 강습 인접, 소스 활동/요일/비활성/장소, 체크포인트 재개·재확인 한도를 확장해 통과.
- 실제 native main/collectSource를 브라우저/공개 API만 모의하여 세 경계를 확인: 이미 본 당일 글 우선 재독 후 미확정이면 잔여 유지, 공개 반영되면 완료, 공개 API 실패면 완료 시각 유지 및 재시도. 모의 실행은 운영 API 저장을 하지 않았다.
- AI/원문 DOM/관리자 삭제/정규 소셜 보존 63개 및 기존 잠금 3개 통과. 무관한 UI 전체 빌드·DB 마이그레이션 검사는 변경 경계 밖이라 제외.
- 네오 공식 `https://www.instagram.com/neo_swing/p/DdDYinBzasB/`를 브라우저에서 새로 읽어 09.13(일), DJ 아홉, 해피홀 주소를 확인. 기존 AI 추출 및 독립 근거 검증 0.99 승인. 기존 `postCandidate`와 자동등록 API로 당일 소셜 한 건만 저장·등록했다. 이벤트 `ed2f0a36-7ce5-4ee7-9ab8-4447f5d24177`, 후보 `0fb96803b8819601`.
- 공개 API에서 해피홀 실제 공지 1건, 미정 생성본 0건, 오늘 경성홀 삭제 일정 0건 확인. 전체 등록 소스를 대조한 당일 잔여 미확정 소스는 0개. 이 값은 오늘 등록된 정규 생성본 범위의 확인 결과이며 모든 공지 수집률로 해석하지 않는다.
- 별도 기존 이슈: 같은 주간 공지의 '9월 2주/라인강습 쉬어갑니다'에서 과거 9/2 수동검토 휴무 후보가 건조 실행에 나타났다. 자동등록은 기존 정책으로 차단되었고 이번 복구에는 저장하지 않았다. 휴무 판독 구조 변경은 이 재시도 연결 작업에서 제외했다.
