# 악기별 그루브 실험 기능을 독립 라우트로 분리

- 날짜: 2026-08-04
- 상태: accepted

## Context

기존 `/tempo-tool`은 BPM 탭 측정과 균등 박자 재생에 초점을 둔다. 스윙·셋잇단음·셔플을 같은 분할 버튼의 변형으로만 다루면 실제 재즈 리듬 섹션에서 악기마다 다른 발음 위치와 역할을 설명할 수 없다. 아직 검증 중인 그루브 모델을 운영 도구에 바로 결합할 경우 단순 메트로놈의 동작도 함께 복잡해진다.

조사에서는 다음 근거를 채택했다.

- Friberg & Sundström(2002): 라이드 심벌의 스윙 비율은 템포가 빨라질수록 감소하고, 고정 2:1은 특정 템포에서만 나타난다.
- Butterfield(2010): 표준 재즈 라이드 패턴은 네 박의 라이드, 2·4박 하이햇, 2·4박 뒤의 짧은 라이드 탭으로 구성된다.
- Columbia Center for Jazz Studies: 워킹 베이스는 한 마디의 네 박을 모두 짚는 역할이다.
- `An Approach to Comping`: Charleston은 다운비트와 업비트를 결합하는 기본 재즈 컴핑 어휘다.
- W3C MusicXML: 스윙은 두 음의 비율로 표현되며 2:1 재생을 명시할 수 있다.
- Alfred Music의 셔플 설명: 셋잇단 격자의 첫째·셋째 칸을 사용하고 가운데 칸은 쉰다.
- 피아노 트리오 연구와 블루스 악기 자료: 부기우기의 eight-to-the-bar 왼손 및 근음–5도/6도 교대 어법을 채택한다.
- Grove Music의 blue note 항목과 Eastman 연구: 블루 노트는 리듬이 아니라 3·5·7도 주변의 가변적인 음높이 표현이다.

## Decision

- 실험 기능은 기존 메트로놈과 합치지 않고 `/groove-lab`에 둔다.
- 바텀 메뉴의 커스텀 앱 목록에는 `개발중`으로 표시하고 `BETA` 배지를 붙인다. 사용자의 고정 메뉴에는 강제로 추가하지 않으며, 기존 메뉴 편집 기능에서 직접 선택하게 한다.
- 프리셋은 음색만 바꾸지 않고 `악기 역할 + 한 마디 발음 위치 + 강세 + 음색`을 한 단위로 정의한다.
- 첫 범위는 여덟 계열 28개 프리셋으로 둔다. 재즈 스윙, 셔플·부기, 3연·12/8, 펑크 16비트, 보사·삼바, 아프로쿠반, 록·팝, 블루 노트를 포함한다. 각 계열은 대표 드럼·타악기와 베이스·기타·건반 역할을 가능한 범위에서 분리한다.
- `라이드 스윙`은 드러머의 라이드 심벌 측정 경향을 잇는 교육용 선형 보간으로 명시한다. 솔리스트를 포함한 정확한 연주 법칙이나 개인 스타일의 복제로 표현하지 않는다.
- 균등 셋잇단음과 셔플은 고정된 3분할 격자를 사용한다. 스윙 프리셋에서는 `실연 스윙`, 정확한 `2:1 3연`, `1:1 스트레이트`를 비교할 수 있다.
- 블루 노트는 독립 리듬으로 취급하지 않는다. 선택한 타이밍 위에서 보컬·관악·기타의 연속 피치 굴절과 피아노의 고정 건반 근사를 별도 음색으로 비교한다.
- 근거 링크와 단순화 한계를 화면 안에서 확인할 수 있게 한다.
- 발현·기타·베이스·클라비넷 계열은 Karplus–Strong 지연선 모델을 사용하고, 북·심벌 계열은 타격 잡음과 비정수 다중 모드를 결합한다. 모든 프리셋 출력은 DC 차단과 다이내믹 압축을 거쳐 동시 타격의 클리핑 위험을 줄인다. 출처 없는 공통 톤 보정은 사용하지 않고 측정값이 있는 보이스 전용 필터만 허용한다.
- 합성 파라미터는 물리적 원리를 그대로 주장하지 않고 연구에서 채택한 구조와 공학적 신호 목표를 분리한다. 내부 수치 탐색 스텝 수를 연구·검증 회차로 표시하지 않는다. 실제 적응형 회차는 새 근거 또는 교차검증, 코드·데이터 수정, 해당 변경의 검증, 다음 질문이 모두 남은 경우에만 별도 원장에 센다.
- 삼바 판데이루의 연구 예시는 보고된 16분음표 길이 23.0%·23.6%·22.8%·30.7%를 한 박 안에서 정규화한다. 이는 한 실연 자료의 교육용 기준이며 모든 삼바의 보편 격자로 표현하지 않는다.

## Consequences

- 기존 `/tempo-tool`의 저장·재생 계약은 바뀌지 않는다.
- 그루브 모델을 나중에 합치려면 사용자 검증 후 엔진 데이터와 오디오 스케줄러를 선택적으로 이관할 수 있다.
- 템포나 프리셋 변경 시 이전에 예약된 Web Audio 출력은 별도 출력 노드에서 즉시 음소거해 패턴 중첩을 방지한다.
- 실제 연주는 곡, 연주자, 앙상블 상호작용에 따라 달라지므로 이 기능은 반주 생성기가 아니라 교육·비교용 프리셋으로 유지한다.
- 합성기는 실제 샘플 녹음을 대체하지 않는다. 대신 반복 연습에서 음높이·발음·강세가 재현 가능하고 브라우저별 피크가 안전한 절차적 기준음을 제공한다.
- 공개 구현은 논문 또는 연구기관과 연결된 Stanford CCRMA STK와 Stanford·GRAME Faust Physical Modeling Library를 우선 대조한다. 개인 데모 저장소의 파라미터를 단독 근거로 채택하지 않는다.
- 근거는 타이밍·패턴·악기 주법·피치·합성·한계 주장으로 분리한다. 각 프리셋은 논문·표준·대학 연구·대학원 논문·고등교육 기관 중 직접 근거를 최소 하나 가져야 하며 자동 감사가 이를 강제한다.
- 모든 합성 프리셋은 현재 포함한 요소와 아직 제외한 물리 요소를 함께 표시한다. 공개 구현도 완전한 몸통 모델을 제공하지 않는 경우 이를 숨기지 않으며 `실제 악기 완전 재현`으로 표현하지 않는다.
- 연습 모드는 계속 듣기 외에 2마디 청취·2마디 무음 콜백과 작은 폭의 비무작위 템포 사다리를 제공한다. 임의 미세타이밍을 전 악기에 공통 인간화로 추가하지 않는다.
- 공개 DSP 원코드의 계산 계약도 회귀 테스트로 고정한다. STK 방식의 플럭 위치와 자기 픽업 위치는 모두 왕복 현 지연의 절반을 기준으로 하지만, 전자는 초기 여기 필터이고 후자는 출력 콤 필터이므로 한 파라미터로 합치지 않는다. 자기 픽업은 전기 베이스 계열에만 적용하고 업라이트에는 적용하지 않는다.
- 피아노는 저음 단현, 중음 2현, 고음 3현의 독립 유니즌 묶음과 측정 범위 안의 미세 주파수 차이를 사용한다. 이는 비팅의 경량 근사이며, 측정값이 필요한 브리지 결합·이중 감쇠·사운드보드는 구현 범위에서 제외한다.
- 클라비넷은 실제 D6 측정에서 확인된 매 5번째 배음 픽업 노치를 한 가지 연구 기준 프리셋으로 재현한다. 실제 두 픽업의 선택·역상 조합, 자기 비선형, 네 톤 스위치를 구현한 것으로 확대 해석하지 않는다.
- 클라비넷의 톤 스위치 제외 기본 앰프는 연구에서 보고된 −3 dB@130 Hz 저역 셸프와 +3 dB@4 kHz 고역 셸프만 해당 보이스에 적용한다. 측정 근거가 없는 공통 앰프 왜곡이나 캐비닛 EQ로 다른 현악기까지 한꺼번에 처리하지 않는다.
