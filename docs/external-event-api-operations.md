# 외부 일정 API 관리자 운영 안내

이 문서는 Dance Billboard 관리자용입니다. 파트너에게는 `docs/external-event-api.md`와 OpenAPI 파일만 전달해 주세요.

## 최초 운영 준비

다음 마이그레이션이 적용되어 있어야 합니다.

```text
server/cafe24/migrations/2026-07-26-external-events-api.sql
```

## 관리 화면

Dance Billboard에 관리자 계정으로 로그인한 뒤 다음 경로를 사용합니다.

`햄버거 메뉴 → 관리자 콘솔 → API 연동`

관리 화면에서는 다음 작업을 할 수 있습니다.

- 외부 연동 신청 확인 및 테스트 키 승인
- 테스트 모드에서 운영 모드로 전환
- 파트너 키 직접 발급 및 기존 키의 즉시 재발급
- 키를 사용할 Dance Billboard 회원 계정 연결
- 사용 중지·재활성화
- 허용 장르 복수 선택(미선택 시 전체 허용)과 호출 한도 설정
- 파트너별 API 요청 기록과 관리자 변경 기록 확인

## 회원 계정과 API Key의 관계

API Key는 관리자 아이디에 발급하지 않습니다. 일정을 실제로 공급하는 파트너를 먼저 Dance Billboard 회원 계정에 연결한 뒤, 그 파트너 연동용 키를 발급합니다.

- 연결 회원: API로 생성된 일정의 내부 소유자
- 파트너 API Key: 외부 서버가 등록·수정·삭제할 때 사용하는 서버용 인증정보
- 관리자 계정: 키 발급·중지·재발급·설정 변경·기록 조회 권한

따라서 현재 두 관리자 아이디는 어느 파트너 키를 누가 관리했는지 추적하는 관리자이며, 파트너 일정의 소유자로 자동 지정되지 않습니다. 파트너가 바뀌면 관리 화면에서 연결 회원을 변경할 수 있습니다.

키 원문은 발급 또는 재발급 직후 한 번만 표시됩니다. 안전한 채널로 담당자에게 전달하고 비밀 저장소에 보관하도록 안내해 주세요. DB에는 키 해시만 저장됩니다.

신규 승인은 테스트 모드로 시작합니다. 이 모드에서는 요청값과 권한을 검사하고 기록을 남기지만 실제 일정을 생성·수정·삭제하지 않습니다. 호출 기록에서 연동이 정상임을 확인한 다음 운영 모드로 전환해 주세요.

키 유출, 오등록 또는 계약 종료 시 해당 파트너를 즉시 중지하거나 재발급해 주세요. 재발급하면 이전 키는 바로 폐기됩니다. 파트너별 요청 IP·결과·상태 코드·시각과 관리자별 변경 기록은 `기록` 탭에서 함께 확인할 수 있습니다.

관리 화면의 변경 요청은 로그인된 관리자 세션과 동일 출처 요청을 모두 확인합니다. 파트너 API 요청에는 웹 로그인 쿠키를 사용하지 않으며 파트너별 API Key만 사용합니다.
