## 왜 적게 잡혔는가

**증상 → 판정 → 부작용 → 원장/공개 결과**: 최신 공식 공지가 존재하지만 후보가 없음 → Instagram 프로필의 고정 글 정렬은 `textContent`만 보고 실제 SVG/이미지의 접근성 라벨을 놓침 → 적은 게시물 탐색 한도를 오래된 고정 글이 먼저 소진 → 최신 소셜 누락. 보니따 프로필에서 오래된 고정 공지와 그 아래 최신 9/23 공지를 직접 대조했다.

기존 구현은 **일부 있음**이다. `collectInstagramLinks`의 고정 글 후순위 처리는 이미 있었다. 해당 줄의 `bfd54fc99` 도입과 `dcd369e00`의 48개 상한, 직접 호출부·기존 DOM 테스트를 확인했다. 기존 익명 DOM 읽기를 같은 유틸 파일의 `readInstagramProfileDocument`로 옮겨 아이콘 라벨을 읽도록 연결했다. 별도의 탐색기·저장기·DB·상태값은 없다.

기존 보호 목적은 고정 월간 일정도 보존하면서 최신 글을 우선하고, 제한된 접근/실행 예산과 출처 소유권을 지키는 것이다. 고정 글 삭제 없이 순서만 조정했고 URL 중복 제거·48개 상한·월간 고정 공지·작성자 필터·접근 제한 중단을 유지했다. 특정 보니따 글 전용 예외가 아니다.

홍턴과 바바루는 기존 등록이 없음을 레지스트리에서 확인한 뒤 공식 운영자 출처로 추가했다. 둘 다 기존 수동 검수 정책이며, 살사 Instagram 예약 선택 대상은 발견용 허브를 제외한 **19개**가 됐다. 별도 예약 작업은 추가하지 않고 앞서 설치한 지역 수집 작업이 기존 레지스트리를 읽는다.

## 실제 씬에서 확장할 경로

장소 이름 목록만으로는 부족하다. **동호회 → 공동 게시물 → 장소 운영자 → 날짜별 포스터**를 따라가야 한다. 이번 대구 바바루는 살사드라마에서 연결된 공동 게시물로 찾았으며, 광주는 마얀 계정뿐 아니라 운영자 계정과 공개 카페 경로까지 확인했다. 게시 빈도가 낮은 계정을 곧 지역 활동 부재로 해석하지 않는다.

지역·서울 공식 Instagram 9개 추가 시험은 문서 28개를 판별했으며 원시 후보 3개를 반환했다. 저장 없는 시험이므로 ‘신규 3건’ 로그를 저장 실적으로 계산하지 않았다. 구미 아르떼·펠리즈·창원 라틴블라썸은 로그인 제한으로 중단했다. 나머지에는 과거 행사 영상·강습·휴강 공지가 섞여 있었다.

- 강남 원시 후보는 다른 슬라이드의 10/4를 강습에 붙였으므로 사용하지 않고 위 원본 포스터별 5건으로 검수했다.

자동 파서가 복합 포스터/휴강을 항상 정확하게 분류한다는 검증은 끝나지 않았다. 이번 실제 오류 후보는 원문 검수로 제외·재구성했으며, 새 출처의 자동 공개 정책은 올리지 않았다.
