# Upright bass sample source

The files in this directory are derived from the **VSCO 2 Community Edition**
Solo Contrabass Pizzicato recordings:

- Source: https://github.com/sgossner/VSCO-2-CE/tree/master/Strings/Solo%20Contrabass/Pizz
- Project license: CC0 1.0 Universal
- Recording: Sam Gossner and Simon Dalzell
- Sample editing credited upstream: Elan Hickler / Soundemote

Included source notes are `E0`, `G0`, `A#0`, and `C1` in the upstream file
naming convention. The upstream SFZ maps these to sounding MIDI notes 28, 31,
34, and 36 (E1, G1, B-flat1, and C2 in scientific pitch notation). Two
round-robin recordings are included for each note.

For browser delivery, the original WAV files were converted to 128 kbps MP3
and loudness-normalized to -20 LUFS with a -2 dB true-peak ceiling. No synthetic
body resonance or pitch correction was added to the source recordings.

The full CC0 text is available in the upstream repository:
https://github.com/sgossner/VSCO-2-CE/blob/master/LICENSE
